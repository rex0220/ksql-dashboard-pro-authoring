# docs/ について

仕様 3 文書(設定ファイル仕様・レシピ集・オーサリング手順)とサンプルは、
kSQL Dashboard Pro 開発リポジトリからのコピーです。
プラグインのリリースに合わせて更新されます(このリポジトリ側では編集しない)。
[指示レシピ例.md](指示レシピ例.md) だけはこのテンプレート固有の文書です。

- `npm run check:sql` など開発リポジトリの CI に関する記述は、このリポジトリには
  該当する仕組みがありません(生成した SQL の検証は kSQL MCP の `ksql_validate` で行います)

| ファイル | 内容 |
| :--- | :--- |
| 指示レシピ例.md | **AI への指示の書き方の実例**(作成・変更・準備作業) |
| 設定ファイル仕様.md | 設定 JSON の形式の正本 |
| ダッシュボードレシピ集.md | SQL の書き方と設計原則 |
| AI設定オーサリング手順.md | 作業手順の詳細 |
| samples/ | 動作確認済みの実例(雛形) |
